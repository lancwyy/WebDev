# Web Development Course Code Examples

This repository is used to share practical code examples for a Web Development course. The materials are organized by topic according to the course schedule and are intended as learning references for students.

## Project Purpose

The examples in this project cover the main web technologies taught in the course, including:

- HTML5
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

Each folder contains sample code, exercises, and small examples to help understand the concepts discussed in class.

## Contents by Topic

### HTML5
Examples for semantic elements, multimedia, forms, tables, lists, and page layout.

### CSS
Examples for selectors, box model, layout, color, typography, responsive design, and styling techniques.

### JavaScript
Examples for variables, functions, arrays, objects, DOM manipulation, events, loops, and JavaScript programming logic.

### Node.js
Examples for server-side JavaScript, modules, file system operations, HTTP server basics, and backend concepts.

### Express.js
Examples for routing, middleware, request handling, templates, REST APIs, and server-side application structure.

### MongoDB
Examples for database connection, CRUD operations, schema design, and integration with Node.js and Express.

## How to Use

1. Open the folder for the topic you are learning.
2. Read the HTML, CSS, JavaScript, or server-side code examples.
3. Run the examples in a browser or with Node.js depending on the technology.
4. Modify the code to test your understanding and practice.

## Notes

- This repository is intended as a learning and demonstration resource.
- Some examples may be simplified for classroom use.
- Students are encouraged to experiment and build on the provided sample code.
