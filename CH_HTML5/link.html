Link Demo: Fragments and URL Schemes

1. Sections of a page with document fragments

This example uses named ID fragments to jump to different sections on this page.

Go to Section A Go to Section B Go to Section C

Section A

This is the first section. Document fragments can jump directly to an element with the corresponding id.

Section B

This is the second section. Clicking the link will scroll to this section within the same page.

Section C

This is the third section. Document fragments are commonly used for table of contents and in-page navigation.

2. Specific text portions with text fragments

Text fragments allow the browser to highlight specific text when opening a link.

Highlight "Section A" Highlight "Section B" Highlight "third section"

The links above include a text fragment fragment identifier using #:~:text=....

3. External links

External links direct users to resources on other websites.

Visit MDN Web Docs Visit W3C

4. Telephone numbers with tel: URLs

Clicking a tel: link prompts the device to call the phone number.

Call +1 234 567 890

5. Email addresses with mailto: URLs

Clicking a mailto: link opens the user's default email app with a new message.

Email someone@example.com

6. SMS text messages with sms: URLs

Clicking a sms: link opens the phone's messaging app to send a text.

Send SMS to +1 234 567 890

7. Incorrect URLs

Clicking an incorrect URL may result in an error or unexpected behavior.
