CSS Combinator Selector 常用場景

這個範例展示四種常見組合選擇器：後代選擇器、子選擇器、一般兄弟選擇器、緊鄰兄弟選擇器。

1. selector1 selector2（後代選擇器）

1.1 這一段被 .parent p 命中

這一段也被 .parent p 命中

1.3 這一段沒有被 .parent p 命中
命中：.parent p

2. selector1 > selector2（子選擇器）

2.1 這一段被 .menu > .item > span 命中

2.2 這一段不是直接子元素，所以不會被命中

命中：.menu > .item > span

3. former_element ~ target_element（一般兄弟選擇器）

3.1 這一段不是目標

3.2 這一段被 .before ~ p 命中

3.3 這一段也被 .before ~ p 命中

3.4 這一段也被 .before ~ p 命中

命中：.before ~ p

4. former_element + target_element（緊鄰兄弟選擇器）

4.1 這一段不是目標

4.2 這一段被 .lead + .target 命中

4.3 這一段不是緊鄰元素，不會被命中

命中：.lead + .target
