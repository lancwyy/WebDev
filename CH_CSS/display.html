CSS display 屬性示範

display 決定元素如何參與頁面排版。觀察每個區塊中藍色方框的位置與尺寸變化。

display: block

區塊元素會另起一行，預設會占滿可用寬度。

display: inline

行內元素會接在同一行；設定的寬度與高度不會生效。

display: inline-block

元素會像行內內容一樣排列，但可以設定寬度與高度。

display: contents

元素本身不產生版面方框（不占自己的 normal flow 位置）；其子元素則像直接放在父層容器中，參與父層的排版。注意：子元素仍然會顯示，這和 display: none 不同。

下面的綠色項目都直接參與同一個 Grid：中間兩項在 HTML 中包在 .contents-wrapper 裡，但包裝層不產生方框，也不占一個格子。紅色虛線框與底色是包裝層的樣式，因為它沒有產生方框，所以看不到。

常見情境：保留 HTML 的語意結構、元件包裝或程式操作所需的父元素，但希望其子元素能直接成為外層 Flex/Grid 容器的項目。使用前也要確認目標瀏覽器與輔助科技的支援情況；若父層本身需要背景、邊框或可見的版面方框，就不適合使用。
