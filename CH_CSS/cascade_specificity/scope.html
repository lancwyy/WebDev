@scope：較近的 Scope Root 勝出

當同一元素同時符合多個 @scope 區塊中的規則，而相關宣告在 Cascade 中的優先層級與 specificity 都相同時，瀏覽器會比較 scope proximity：距離目標元素較近的 scope root 所屬規則勝出。

重疊的 Scope 範圍

目標元素位於外層與內層兩個 scope 中。兩條規則的選擇器都是 .target，特異性相同（(0, 1, 0)）。內層 scope root 距離目標元素較近，所以文字應呈藍綠色。

外層 scope root：.outer-scope
內層 scope root：.inner-scope

目標元素：內層 scope 的藍綠色規則勝出

HTML 結構

<div class="outer-scope">
  <div class="inner-scope">
    <p class="target">目標元素</p>
  </div>
</div>

CSS 規則

特意先寫內層 scope，再寫外層 scope。若只看相同特異性下的 source order，後寫的外層規則似乎會勝出；但 scope proximity 優先於 source order，因此實際上由較近的內層 scope 勝出。

/* 選擇器 specificity：(0, 1, 0) */
@scope (.inner-scope) {
  .target { color: teal; }
}

/* 同為 (0, 1, 0)，而且這條規則寫得較晚 */
@scope (.outer-scope) {
  .target { color: red; }
}

scope proximity 是 Cascade 中較後面的比較條件：只有 origin、importance、cascade layer、specificity 等前置條件相同時，才會用 root 到目標元素的 DOM 距離決勝。它不是無條件讓內層規則蓋過更高優先級或更高 specificity 的規則。此頁示範需使用支援 CSS @scope 的瀏覽器。
