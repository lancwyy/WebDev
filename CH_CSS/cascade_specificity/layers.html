CSS Cascade Layers：@layer 優先順序

@layer 可將 CSS 規則分組，並明確決定不同群組的優先順序。比較不同 layer 時，layer 順序先於 specificity 和 source order；選擇器寫得更精確，不會讓低優先 layer 的規則勝過高優先 layer 的規則。

宣告 Layer 順序

以下順序由低至高排列一般宣告的優先級。未放入任何 layer 的作者一般樣式，優先級高於所有 layered 一般樣式。

@layer reset, components, utilities;

一般宣告（低 → 高）：reset → components → utilities → 未分層樣式。

Layer 順序以首次建立 layer 的位置為準。可在 CSS 前段集中宣告順序，避免之後載入順序改變造成難以預期的結果。

一般宣告：後面的 Layer 勝出

三條規則的選擇器相同，元素同時符合每一條。utilities 在宣告順序中較後，因此綠色勝過 components 的橘色和 reset 的紅色。

結果：綠色（utilities layer 勝出）

HTML

<p class="normal-layer-demo">分層的一般宣告</p>

CSS

@layer reset, components, utilities;

@layer reset {
  .normal-layer-demo { color: red; }
}
@layer components {
  .normal-layer-demo { color: darkorange; }
}
@layer utilities {
  .normal-layer-demo { color: green; }
}

未分層的一般宣告勝過所有分層一般宣告

即使 reset 中的規則出現在前面，未分層的一般宣告仍然勝出，所以文字呈藍色。未分層規則適合用來覆寫 layer，但也可能讓分層架構較難管理。

結果：藍色（未分層的一般宣告勝出）

HTML

<p class="normal-unlayered-demo">分層與未分層的一般宣告</p>

CSS

@layer reset {
  .normal-unlayered-demo { color: red; }
}

/* 未分層的一般作者樣式高於任何 layer 的一般樣式 */
.normal-unlayered-demo { color: blue; }

!important：Layer 順序反轉

對 !important 宣告，layer 優先順序會反轉：reset（最先宣告）高於 components，也高於 utilities。因此雖然綠色規則位於較後的 layer，最先宣告的 reset layer 紅色勝出。

結果：紅色（reset layer 的 !important 勝出）

HTML

<p class="important-layer-demo">分層的 !important 宣告</p>

CSS

@layer reset, components, utilities;

@layer reset {
  .important-layer-demo { color: red !important; }
}
@layer components {
  .important-layer-demo { color: darkorange !important; }
}
@layer utilities {
  .important-layer-demo { color: green !important; }
}

分層的 !important 勝過未分層的 !important

這和一般宣告相反：任何 layer 中的 !important 都高於未分層的 !important。由於 reset 是最先建立的 layer，它的紅色宣告勝過未分層的藍色宣告。

結果：紅色（reset layer 的 !important 勝過未分層 !important）

HTML

<p class="important-unlayered-demo">分層與未分層的重要宣告</p>

CSS

@layer reset, components, utilities;

@layer reset {
  .important-unlayered-demo { color: red !important; }
}

/* 未分層的 !important 低於分層的 !important */
.important-unlayered-demo { color: blue !important; }

重點整理

  • 一般宣告：後建立的 layer 優先；未分層一般宣告高於所有分層一般宣告。
  • !important 宣告：layer 順序反轉，較早建立的 layer 優先；分層重要宣告高於未分層重要宣告。
  • 只有在相同 origin、importance 和 layer 層級中，才進一步比較 specificity 與 source order。

這裡展示的是同一來源（Author Styles）下的 layer 優先順序。不同樣式來源（例如 User 或 User-Agent）的優先順序，仍依 CSS Cascade 的 origin and importance 規則處理。
