CSS Cascade：樣式優先順序

當多個 CSS 宣告設定同一元素的同一屬性時，瀏覽器會依 Cascade 規則決定最後採用哪個值。以下由低至高排列；最後適用的優先層級勝出。

優先順序（低 → 高）

  1. User-Agent Styles（瀏覽器預設樣式）
  2. User Styles（使用者自訂樣式，例如瀏覽器設定或擴充功能）
  3. Author Styles（作者一般樣式：外部、嵌入式、行內樣式）
  4. CSS Animations（正在執行的 @keyframes 動畫）
  5. Author Styles（作者的 !important）
  6. User Styles（使用者的 !important）
  7. User-Agent Styles（瀏覽器的 !important）
  8. CSS Transitions（正在進行的屬性轉場；優先權最高）

這是樣式來源與重要性（origin and importance）的順序。當宣告位於相同層級時，還要比較 cascade layers、specificity 與 source order；行內樣式仍屬於作者的一般樣式，不會因此高於作者的 !important。

User-Agent Styles（瀏覽器預設樣式）

瀏覽器會為 HTML 元素提供預設樣式，例如標題的粗體與較大字級。以下 HTML 通常會直接呈現瀏覽器預設樣式；CSS 範例只用來示意類似的預設規則，不是網頁能設定的 User-Agent stylesheet。

HTML（頁面作者提供）

<h2>瀏覽器預設的標題</h2>
<p>瀏覽器預設的段落</p>

CSS（示意瀏覽器可能提供的預設樣式）

/* 概念示意；實際規則依瀏覽器而異 */
h2 { display: block; font-size: 1.5em; font-weight: bold; }
p  { display: block; margin-block: 1em; }

User Styles（使用者一般樣式）

使用者可透過瀏覽器支援的使用者樣式表或擴充功能，自訂頁面外觀，例如放大文字。這些 CSS 不屬於網站作者的 HTML/CSS，能否加入取決於瀏覽器或擴充功能。

HTML（網站頁面中的目標元素）

<p class="sample">這段文字可由使用者樣式調整</p>

CSS（使用者樣式表／擴充功能提供）

/* 由使用者環境載入，不是放在網站頁面中 */
.sample { font-size: 1.5em; color: darkgreen; }

Author Styles（作者一般樣式）：外部、嵌入式、行內

以下三種都屬於 Author Styles（Normal）。作者一般樣式先比較 cascade layer；同一層級再比較 specificity 與 source order。行內一般樣式通常勝過一般選擇器規則，但仍低於作者的 !important。

外部樣式表（styles.css）

/* 外部樣式表：<link rel="stylesheet" href="styles.css"> */
.sample { color: steelblue; }

嵌入式樣式（HTML 的 <style>）

<style> /* 嵌入式樣式 */
  .sample { color: seagreen; }
</style>

行內樣式（HTML 元素的 style 屬性）

<p class="sample" style="color: darkorange">行內樣式</p>

這個元素實際使用行內一般樣式（橘色）。

動畫高於作者一般樣式

下方文字有一般作者樣式（綠色 #046a21），同時 @keyframes 在藍色與紫色間動畫；動畫期間的值會蓋過一般作者樣式。

HTML

<p class="animation-demo">顏色會隨動畫改變</p>

CSS

.animation-demo { color: #046a21; animation: color-shift 3s infinite alternate; }
@keyframes color-shift {
  from { color: #2563eb; }
  to   { color: #9333ea; }
}

觀察文字顏色在藍色與紫色之間變化

作者 !important 高於動畫

這個元素也套用相同動畫，但作者的 color: ... !important 勝過動畫，因此文字維持紅色。

HTML

<p class="important-demo">作者重要宣告勝出</p>

CSS（與上方動畫相同，再加上重要宣告）

.important-demo { color: #2563eb; animation: color-shift 3s infinite alternate; }
.important-demo { color: #dc2626 !important; }

作者 !important 勝出，文字維持紅色

User Styles !important

使用者的 !important 高於作者的 !important。例如使用者可用重要宣告強制頁面文字採用高對比色；這段 CSS 必須由瀏覽器或擴充功能以使用者樣式載入。

HTML（網站頁面中的目標元素）

<p class="sample">使用者重要樣式可覆寫網站顏色</p>

CSS（使用者樣式表／擴充功能提供）

/* 使用者來源的 !important */
.sample { color: black !important; background: yellow !important; }

請注意：一般頁面作者不能把這段 CSS 放在自己的樣式表，就使它成為 User Styles。

User-Agent Styles !important

瀏覽器內部樣式表也可能有 !important 宣告，其優先權高於使用者與作者的 !important。一般網頁無法建立 User-Agent 樣式，以下僅為瀏覽器內部規則的概念示意。

HTML（頁面中的目標元素）

<div hidden>這個元素預設隱藏</div>

CSS（概念示意；不可由網頁作者宣告為 User-Agent 樣式）

/* 某些瀏覽器的 UA stylesheet 會以 !important 保持 hidden 的語意 */
[hidden] { display: none !important; }

/* 作者來源即使使用 !important，仍低於 UA !important */
[hidden] { display: block !important; }

轉場高於 !important

將滑鼠移到下方文字上（或用鍵盤聚焦互動元素）：顏色會在紅色與藍綠色間轉場。轉場進行時，其目前的值優先於其他來源的宣告，包括 !important。

HTML

<p class="transition-demo" tabindex="0">移入或聚焦以觸發轉場</p>

CSS

.transition-demo {
  color: #dc2626 !important;
  transition: color 1s ease;
}
.transition-demo:hover,
.transition-demo:focus {
  color: #0891b2 !important;
}
