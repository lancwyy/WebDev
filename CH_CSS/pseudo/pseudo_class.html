CSS Pseudo-classes（偽類）

Pseudo-class（偽類）以冒號 : 開頭，用來依元素的狀態、使用者互動或文件結構選取元素；不需要在 HTML 加上額外的 class。

Pseudo-class 偽類 Pseudo-element 偽元素

互動狀態：:hover、:focus-visible

將滑鼠移到連結上，或用鍵盤 Tab 聚焦連結，觀察不同狀態的樣式。

移入或用鍵盤聚焦我

HTML

<a class="demo-link" href="#target-example">移入或聚焦我</a>

CSS

.demo-link:hover {
  color: white;
  background: blue;
}
.demo-link:focus-visible {
  outline: 3px solid orange;
}

文件結構：:first-child、:nth-child()

第一個項目會加粗，奇數項目使用淺藍色背景。

  • 清單項目一
  • 清單項目二
  • 清單項目三
  • 清單項目四

HTML

<ul class="demo-list">
  <li>清單項目一</li>
  <li>清單項目二</li>
  <li>清單項目三</li>
</ul>

CSS

.demo-list li:first-child { font-weight: bold; }
.demo-list li:nth-child(odd) { background: lightblue; }

表單狀態：:checked、:focus、:valid、:invalid

勾選選項後標籤變綠；文字欄位聚焦時顯示焦點外框，並依輸入是否符合 required 狀態呈現顏色。

HTML

<input class="choice" type="checkbox" id="terms">
<label for="terms">我已閱讀說明</label>
<input class="name-input" type="text" required>

CSS

.choice:checked + label { color: green; }
.name-input:focus { outline: 2px solid blue; }
.name-input:invalid { border-color: red; }
.name-input:valid { border-color: green; }

URL 狀態：:target

點擊連結後，網址片段會指向下方元素，該元素符合 :target，背景會改變。

前往目標段落

我是 URL 片段所指向的目標元素。

CSS

.demo-target:target {
  background: lightyellow;
  outline: 2px solid orange;
}

重點

  • 偽類選取的是符合特定狀態或結構條件的既有元素。
  • 偽類使用單冒號，例如 :hover、:checked。
  • 互動狀態樣式也應照顧鍵盤使用者，例如提供清楚的 :focus-visible 樣式。
