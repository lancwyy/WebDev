CSS Pseudo-elements（偽元素）

Pseudo-element（偽元素）以雙冒號 :: 開頭，用來選取元素的一部分，或建立如前置、後置內容等可樣式化的生成盒。生成內容適合裝飾，不應用來放置不可缺少的資訊。

Pseudo-class 偽類 Pseudo-element 偽元素

生成前後內容：::before、::after

偽元素可在元素內容前後建立生成內容。此處的「NEW」與箭頭是裝飾，實際資訊仍由 HTML 文字提供。

限時優惠商品

查看樣式說明

HTML

<p class="badge">限時優惠商品</p>
<a class="link-note" href="#first-letter-example">查看樣式說明</a>

CSS

.badge::before {
  content: "NEW";
  background: red;
}
.link-note::after {
  content: " ↗";
}

文字片段：::first-letter、::first-line

這些偽元素可針對文字的一部分設定樣式。第一行會依容器寬度與字型排版而改變；縮放視窗觀察時，第一行範圍也可能不同。

偽元素可以讓段落的第一個字母以較大的字級呈現，常用於文章的首字下沉效果。

這個段落的第一行會顯示藍色粗體。調整瀏覽器視窗寬度，瀏覽器會重新排版，因此第一行所包含的文字也會跟著改變。

CSS

.intro::first-letter {
  font-size: 2.5em;
  font-weight: bold;
}
.sample-paragraph::first-line {
  color: steelblue;
  font-weight: bold;
}

表單與清單：::placeholder、::marker

::placeholder 設定輸入欄位的提示文字；::marker 設定清單項目前的標記樣式。

  • 清單項目一
  • 清單項目二
  • 清單項目三

HTML

<input class="text-input" placeholder="請輸入關鍵字">
<ul class="marker-list">
  <li>清單項目一</li>
  <li>清單項目二</li>
</ul>

CSS

.text-input::placeholder { color: gray; }
.marker-list li::marker { color: seagreen; }

}

重點

  • 偽元素針對元素的一部分或生成的盒子套用樣式。
  • 新式語法使用雙冒號，例如 ::before；部分舊式偽元素也支援單冒號寫法。
  • ::before 與 ::after 通常需要 content 才會生成內容。
  • 生成文字不應承載重要資訊，因為它未必能以相同方式被輔助科技讀取。
