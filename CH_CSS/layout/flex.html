CSS Flexbox：主軸與交叉軸

Flexbox（彈性盒）會沿著主軸排列容器內的項目。主軸方向由 flex-direction 決定；交叉軸則與主軸垂直。調整視窗大小，觀察項目換行及尺寸的變化。

1. display: flex 與 flex-direction: row

Flex 容器預設會將直接子元素沿著一列排列。虛線框代表容器，藍色方框代表 flex 項目。

項目 1
項目 2
項目 3
.container {
  display: flex;
  flex-direction: row; /* 預設值 */
  gap: 0.75rem;
}

2. flex-direction: column

改變排列方向，就會將主軸從水平改為垂直。

項目 1
項目 2
項目 3
.container {
  display: flex;
  flex-direction: column;
  gap: 0.75rem;
}

3. justify-content 與 align-items

justify-content 控制項目在主軸上的分布；align-items 控制項目在交叉軸上的對齊。本例讓項目在主軸上平均分散，並在交叉軸置中。

起點
中間
終點
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

4. 使用 flex-wrap 換行

同一列空間不足時，flex-wrap: wrap 會讓項目移到下一列。調整視窗寬度，觀察項目如何換行。

彈性項目 1
彈性項目 2
彈性項目 3
彈性項目 4
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 0.75rem;
}
.item {
  flex: 1 1 180px; /* grow、shrink、basis */
}

5. 使用 flex 簡寫設定彈性尺寸

第一個項目分配到的可用剩餘空間，是其他項目的兩倍。flex 簡寫可設定 flex-grow、flex-shrink 與 flex-basis。

項目一：flex: 2
項目二：flex: 1
項目三：flex: 1
.item:first-child { flex: 2; }
.item:nth-child(2),
.item:last-child { flex: 1; }

6. flex-grow：分配剩餘空間

容器有剩餘空間時，flex-grow 決定項目分配剩餘空間的比例。此例的基準尺寸都是 120px，grow 值為 1 : 2 : 1，因此中間項目分到的剩餘空間是兩側項目的兩倍。

grow: 1
grow: 2
grow: 1
.item { flex-basis: 120px; }
.item:first-child { flex-grow: 1; }
.item:nth-child(2) { flex-grow: 2; }
.item:last-child { flex-grow: 1; }

7. flex-shrink：分攤不足空間

項目的基準尺寸總和大於容器可用空間時，flex-shrink 決定縮小的比例。三項的 basis 都是 240px，shrink 值為 1 : 2 : 1，因此中間項目承擔的縮小量約為兩側項目的兩倍。實際縮小量也會依基準尺寸等因素計算。

shrink: 1
shrink: 2
shrink: 1
.item { flex-basis: 240px; }
.item:first-child { flex-shrink: 1; }
.item:nth-child(2) { flex-shrink: 2; }
.item:last-child { flex-shrink: 1; }

8. flex-basis：設定主軸基準尺寸

flex-basis 設定項目分配或縮減空間前的主軸基準尺寸。此例將 grow 與 shrink 設為 0，讓三個項目分別維持 100px、160px、240px；在窄螢幕可水平捲動此示範區。

basis: 100px
basis: 160px
basis: 240px
.item {
  flex-grow: 0;
  flex-shrink: 0;
}
.item:nth-child(1) { flex-basis: 100px; }
.item:nth-child(2) { flex-basis: 160px; }
.item:nth-child(3) { flex-basis: 240px; }

9. 在兩個軸向置中

在預設的 row 方向中，使用 justify-content 讓項目在水平方向置中，並用 align-items 讓項目在垂直方向置中。

水平與垂直置中
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 180px;
}
