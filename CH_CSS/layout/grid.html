CSS Grid：二維網格版面

CSS Grid 適合同時控制欄與列的二維版面。設定 display: grid 後，容器的直接子元素會成為 Grid 項目，可依網格線、欄列尺寸或命名區域安排位置。

1. 使用 grid-template-columns 建立欄

fr 是可用空間的比例單位。下方三欄按 1 : 2 : 1 分配剩餘空間。

1fr
2fr
1fr
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 0.75rem;
}

2. 使用 grid-template-rows 設定列高

此例建立三欄及兩列，並明確指定列高。未設定固定高度的網格項目會依內容調整。

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 60px 110px;
}

3. 使用 gap 與跨欄／跨列

gap 設定網格項目間距。grid-column 和 grid-row 可以讓項目跨越多個欄或列。

一般項目

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0.75rem;
}
.span-wide { grid-column: span 2; }
.span-tall { grid-row: span 2; }

4. 使用 repeat()、minmax() 建立響應式欄

每個欄寬至少為 150px，有空間時平均延展。auto-fit 會依容器寬度放入可容納的欄數；調整視窗大小觀察變化。

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 0.75rem;
}

5. 使用 grid-template-areas 命名版面

命名區域可用直觀方式安排頁面結構。縮窄視窗時，側欄、內容與其他區塊會依媒體查詢重新排列。

頁首
側欄
主要內容
其他
頁尾
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-areas:
    "header header header"
    "sidebar content extra"
    "footer footer footer";
}
.area-header { grid-area: header; }
.area-sidebar { grid-area: sidebar; }
.area-content { grid-area: content; }
.area-extra { grid-area: extra; }
.area-footer { grid-area: footer; }

Grid 適合規劃二維區域；若只需要沿單一方向排列及分配空間，Flexbox 通常較直接。
